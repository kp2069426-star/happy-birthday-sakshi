# Sakshi Birthday Surprise 💗

A responsive pink birthday surprise website for Sakshi, made by Kishan.

## Files
- `index.html` — page content
- `style.css` — pink design and animations
- `script.js` — surprise buttons, candle interaction, confetti
- `images/` — add photos here
- `music/` — optional folder for music

## Add Sakshi's photos
Put three photo files inside `images/` and name them exactly:
- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`

If you don't add photos, cute placeholders will show instead.

## Publish on GitHub Pages
1. Extract this ZIP on your computer.
2. Open your GitHub repository and choose **Add file → Upload files**.
3. Upload the contents of this folder (not the ZIP). Make sure `index.html` is directly in the repository root.
4. Commit changes.
5. In Settings → Pages, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
6. Open `https://kp2069426-star.github.io/sakshi-birthday/` after a few minutes.

You can also test it by double-clicking `index.html` on your computer.
